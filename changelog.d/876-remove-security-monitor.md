Removed
- The security monitor and its IP blocking are gone. It counted suspicious requests per client IP, could refuse an IP for a while, and served `GET /api/v1/metrics/security`; nobody asked for it. That route now answers `404`, and the Metrics page no longer shows a Security panel. The `security.monitoring.*` and `security.ip_blocking.*` keys (and their `SHELLY_SECURITY_MONITORING_*` and `SHELLY_SECURITY_IP_BLOCKING_*` variables) are no longer read: a config file that still sets them starts as before, with the keys ignored, and the start-up check that refused some combinations of them is gone. The rate limiter, the security headers, CORS and request validation are unchanged. The `component` field of the request log lines changes from `security_monitor` to `security_logging`; the suspicious-request warning is gone. Fixes ginsys/shelly-manager#876.
