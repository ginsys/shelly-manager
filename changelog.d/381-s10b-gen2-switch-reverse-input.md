
- A Gen2 or Gen3 switch now takes `reverse` and `input_id` from a template. Each is written with `Switch.SetConfig` and read back, only where the device's own switch section reports the key; a device that does not report it, an `input_id` other than 0 or 1, and an `input_id` set in the same apply as an input mode are refused before anything is written. A changed `reverse` owes a restart whether or not the answer says so, because the Switch page says setting it requires one. The page names no `model` or `app` value for the devices that have `input_id` (Pro 1, Pro 1 PM, 1L Gen3), so there is no model table and which devices report the keys is unconfirmed on hardware, as are the keys' firmware and the `restart_required` answer. Refs ginsys/shelly-manager#381.
