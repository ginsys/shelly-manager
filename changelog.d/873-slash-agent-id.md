Fixed
- A provisioner agent whose id holds a `/` can now be approved, rejected, deleted, polled and read on the agents page: the five per-agent routes take the id as everything between their fixed parts, so the slash may be sent as it is or as `%2F`. A new agent id with an empty segment (`//`, or a `/` at either end) or a `.` segment, which the routes cannot reach cleanly, or with `..` anywhere, which the security monitor counts as suspicious on every request, is refused with `400`; an id with a single inner `/` still registers. Fixes ginsys/shelly-manager#873.
