Changed
- The export and import detail pages now show the main fields of a result (not the `metadata`, the export `output_path` or `webhook_sent`): status, created time, duration, errors and warnings, and for an import the changes by type with the resource, ID and field of each (never the old or new values). Both link back to the history and use the page and card styling of the device page. The export page's Download button now fetches the file with the admin key and saves it; the old plain link sent no key and got 401 as soon as an admin key was set. The import history page now shows its statistics, and both history pages show the error when the statistics request fails, where they showed zeros before. An import has no download because the API has no such route, and results the server no longer holds in memory still answer "not found" (ginsys/shelly-manager#647). Fixes ginsys/shelly-manager#139.
